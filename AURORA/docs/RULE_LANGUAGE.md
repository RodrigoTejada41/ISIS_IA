# Linguagem de Regras

Exemplos aceitos:

```text
Permita github.com por no maximo 5 paginas.
Bloqueie exemplo.com.
Entre em modo offline total.
Nao pode executar arquivos baixados.
```

Fluxo:

1. analisar texto;
2. gerar estrutura;
3. mostrar interpretacao;
4. ativar somente com confirmacao quando houver risco.
