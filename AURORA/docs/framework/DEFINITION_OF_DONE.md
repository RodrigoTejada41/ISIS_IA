# Definition of Done

Uma tarefa so pode ser marcada como concluida quando:

- Foi aplicada no projeto correto.
- O arquivo correto foi identificado antes da edicao.
- A alteracao e funcional, nao apenas visual, quando o requisito exigir operacao real.
- O comando, link ou endpoint de teste foi informado.
- A validacao executada foi registrada.
- Estado, decisao ou bug relevante foi documentado.
- Nao ha regressao conhecida omitida.
