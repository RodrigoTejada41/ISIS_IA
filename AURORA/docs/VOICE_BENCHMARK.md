# Benchmark de Voz

Gerar:

```powershell
python -m aurora.cli voice-benchmark
```

Saidas:

- `D:\ISIS_IA\ISIS\logs\voice_benchmark.json`
- `D:\ISIS_IA\ISIS\logs\voice_benchmark.md`

Campos atuais:

- motor;
- voz;
- disponibilidade;
- status;
- tempo de sintese;
- audio gerado;
- erro.

RAM/VRAM e qualidade subjetiva ainda dependem de etapa posterior com medicao de processo e avaliacao humana.
