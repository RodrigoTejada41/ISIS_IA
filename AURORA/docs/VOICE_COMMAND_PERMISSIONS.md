# Comandos de Voz para Permissoes

O microfone do HUD usa o mesmo campo de comando.

Comandos reconheciveis pelo fluxo textual:

- `bloqueie todos os acessos`;
- `entre em modo offline total`;
- `permita github.com`;
- `nao salve esta pesquisa na memoria`;
- `use no maximo cinco paginas`.

Comandos criticos por voz devem exigir confirmacao visual/PIN em etapa futura.
